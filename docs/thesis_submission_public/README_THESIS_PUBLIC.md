## Public repository scope

This public repository contains the source-code submission package and reproducibility documentation.

It does not contain the full local thesis evidence packages, local databases, raw provider payloads, cached API/RPC outputs, API keys, private environment files, or wallet secrets.

## Academic submission package

The full academic submission package, including the original proposal, interim report, final thesis document, final defense presentation, and local evidence index, is maintained separately for supervisor/examiner review.

## Safety boundary

All experiments and system validation were conducted in a demo / paper-trading environment.

The system was not deployed for live trading, did not connect to a wallet, and did not execute real transactions.

The repository should not be interpreted as a production trading system or as proof of live profitability.
