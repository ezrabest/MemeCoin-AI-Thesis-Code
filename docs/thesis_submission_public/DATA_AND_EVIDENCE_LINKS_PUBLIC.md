# Data and Evidence Links - Public Version

## 1. Purpose

This document provides a public, sanitized evidence map for the MSc thesis:

A Multi-Layer AI Framework for Meme-Coin Market Monitoring, Risk Explanation, and Paper-Trading Validation

The purpose is to describe the evidence areas supporting the thesis without publishing local databases, raw provider payloads, API caches, generated audit folders, or private environment files.

## 2. Code repository

The public source-code submission package is available at:

https://github.com/ezrabest/MemeCoin-AI-Thesis-Code

## 3. Evidence boundary

The thesis used local timestamped evidence packages generated during system development, validation, robustness correction, and thesis reporting.

The full evidence packages are maintained separately for academic review. They are not included in the public repository because they may contain large generated files, local database-derived summaries, raw provider responses, cached API/RPC outputs, or local machine paths.

## 5. Thesis-safe interpretation

The evidence packages support the following thesis conclusions:

- The system implemented a multi-layer meme-coin intelligence architecture.
- The system preserved candidate-to-outcome lineage.
- Model-evidence tiers differ materially in retrospective event-level robustness analysis.
- Paper/demo validation was performed without live trading.
- Context was not validated as a uniformly beneficial predictive layer.
- Selected raw-provider activity/provenance context produced only an exploratory FDR10-level signal.
- Semantic Social / Opportunistic classification showed strong local risk-stratification support.
- Wallet-flow was technically recoverable at Solana scale but did not validate whale-entry or whale-exit alpha.
- No live profitability claim is made.

## 6. Materials intentionally excluded from public GitHub

The following materials are intentionally excluded:

- local database files
- generated audit folders
- raw provider payloads
- cached RPC/API responses
- large CSV/JSONL/parquet outputs
- ZIP evidence packages
- API credentials
- private environment files
- wallet secrets
- full academic submission package documents unless separately approved

This public version is intended to support transparency while preserving safety, privacy, and practical repository size.
